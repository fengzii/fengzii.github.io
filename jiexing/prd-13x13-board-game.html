01

背景与目标

Context & Goals

网页上的轻量棋类常在两件事上失衡：规则解释成本过高，或者机器人只会“能走”而没有可感知的难度梯度。13×13 挡板棋把每回合压缩为两个动作——移动一格，或放下一块两格长的挡板——却让“绕路”成为持续发生的策略问题。

本产品把这种对抗做成打开即玩的单页网页：玩家在下方出生点先行，机器人在上方应战，先抵达对方底线行的一方获胜。产品的核心不是功能数量，而是让第一次访问的人在一局之内理解规则，并能在三档难度中感受到真实的决策差异。

目标

  • 规则自助：首次访问的用户无需阅读长文档，即可完成第一步移动和第一次挡板放置。
  • 难度可感知：简单、困难、地狱三档在同一规则、同一资源、同一信息下呈现不同的决策质量。
  • 对局闭环：每一局都以明确的胜负结算结束，并可立即再来一局或调整难度。

产品契约

项目定义
主要用户使用桌面浏览器、希望进行一局短时策略对弈的单人玩家。
触发打开网页。
核心任务在 13×13 棋盘上交替移动或放置挡板，先于机器人抵达对方底线行。
完成条件任一方棋子进入对方底线行，出现胜负结算，且结算后可立即开始下一局。
公平条件机器人使用与玩家相同的规则、相同的挡板数量与相同的可见信息，不进行非法或隐藏操作。
02

范围

Scope

本期只交付一条最小但完整的旅程：进入页面、选定难度、完成对局、结算、再来一局。任何不参与这条旅程的能力都不进入 P0。

P0 范围包含内容为什么必须
对局核心移动、跳跃、挡板放置、胜负判定。构成一局完整对局的最小规则集合。
机器人与难度三档难度、开局选择、机器人合法行动。单人玩家需要对手，且需要可选择的对局强度。
交互与反馈合法落点、挡板预览、非法操作原因。规则必须通过操作被解释，而不是只写在说明里。
对局信息当前回合、双方挡板余量、目标线、难度。玩家不应依赖记忆维持对局状态。
结算与重开胜负展示、再来一局、调整难度。完成对局闭环，避免“赢了以后无事可做”。
规则查阅游戏内规则面板。降低首次理解成本，支持对局中确认边界规则。
本地运行桌面浏览器、无需登录、加载后不依赖服务端。“打开即玩”的前提。

后续与暂不包含

类别内容
P1 候选本地同屏双人、手机竖屏专属布局、音效、战绩与回放、悔棋与提示。
明确不做在线联机、账号体系、匹配、排行榜、观战、AI 自适应难度。

“双人对战”在本期指一名真人与机器人之间的对局；真人同屏与在线真人对抗不在本期范围。

最小完整旅程

打开页面→ 选择难度→ 开始对局 · 你先行→ 移动 / 跳跃 / 放置挡板→ 机器人回应→ 抵达对方底线→ 结算→ 再来一局 / 调整难度

关键恢复路径

  • 非法操作：提示原因，不改变棋盘、库存与回合。
  • 重新开始：玩家回合内可用，需二次确认，当前对局作废。
  • 刷新或关闭页面：当前对局不保存，重新打开回到准备阶段。
03

产品模型

Product Model

棋盘是唯一的策略对象。所有规则、界面反馈与机器人决策都围绕“棋盘格、棋子、挡板、通路”这四个对象展开。

3.1 对局双方

角色棋子出生点目标行先后手
你琥珀色圆形棋子(7, 13)，下方中点第 1 行先手
机器人深青色方形棋子(7, 1)，上方中点第 13 行后手

坐标统一写作 (列, 行)，行列均从 1 开始，自左向右、自上而下计数。

出生点即对方的目标行。你出生在第 13 行中点，机器人出生在第 1 行中点；因此“走到对方出生点所在的那一行”就是胜利条件。

3.2 对象与术语

对象定义
棋盘格13×13 共 169 个格子，每个格子最多容纳一枚棋子。
棋子双方各一枚；移动与跳跃的最小单位都是“一格”。
挡板槽相邻两格之间的边缝。横向与竖向各存在 12×12 个可放置位置，一个挡板覆盖两个连续的格子。
挡板两格长的阻挡物，只存在于格子之间，不占据格子。双方各 10 块，归属只影响剩余数量，阻挡效果对双方相同。
通路从当前格出发，只经上下左右相邻格到达目标行任意格的连续路径。判定通路时只看棋盘边界与挡板，不考虑棋子占位。
回合一方完成且仅完成一个动作（移动、跳跃或放置挡板）的时间单位。

3.3 对局状态

状态进入条件玩家可做退出条件
准备页面加载完成，或从结算选择“调整难度”。选择难度、查阅规则、开始对局。点击开始对局 → 玩家回合。
玩家回合对局开始，或机器人完成行动。移动、跳跃、放置挡板、查阅规则、重新开始。有效行动后无胜者 → 机器人回合；抵达目标行 → 结算。
机器人回合玩家完成有效行动且无人获胜。无；棋盘只读。机器人完成行动 → 玩家回合或结算。
结算任一方抵达对方目标行。再来一局、调整难度、查阅规则。再来一局 → 玩家回合；调整难度 → 准备。

禁止操作：机器人回合与结算阶段操作棋盘；对局进行中切换难度；跳过回合或连续执行两个动作。

3.4 回合循环

玩家行动→ 判定胜负→ 机器人行动→ 判定胜负→ 回到玩家

每个动作结束后立即判定；一旦有人进入对方目标行，对局在该动作完成时结束，不再进入对方回合。

05

功能需求

Functional Requirements

每条需求描述触发条件、处理规则、结果与状态变化；具体规则细节统一引用第 06 章的 R 编号，不在多处重复定义。

FR-01开局与难度

难度选择与开始对局

让玩家在进入棋盘前明确对手强度，并保证每局开始状态唯一。

触发
页面加载完成；或结算后选择“调整难度”。
处理
展示简单 / 困难 / 地狱三档选项，默认选中“简单”；玩家确认后点击“开始对局”。开局时机器人按所选难度初始化，玩家获得先手。
结果
棋盘回到初始位置，双方各 10 块挡板，状态进入玩家回合；难度在状态区常驻显示。
边界
对局开始后难度锁定；如需更换，必须回到准备阶段重新开局。重新开始保留当前难度。
FR-02棋盘呈现

棋盘与对局信息

让棋盘成为唯一视觉焦点，玩家不必记忆任何关键状态。

触发
进入对局，或任意状态发生变化。
处理
以 90° 正俯视呈现 13×13 棋盘；顶部色带标注“你的终点线（第 1 行）”，底部色带标注“机器人的终点线（第 13 行）”。常驻显示当前回合、双方挡板余量、难度与上一手位置。
结果
玩家在任何时刻都能判断：轮到谁、双方还剩多少挡板、自己的目标行在哪里。
边界
窄视口下棋盘等比缩放，不裁切、不产生横向滚动；当棋盘小于可操作尺寸时，优先提示使用更宽的窗口，而不是压缩点击区域。
FR-03移动

移动一格

提供最基础、最频繁的回合动作。

触发
你的回合，处于“移动”模式，点击一个合法的相邻空格。
处理
按 R-02 校验：目标在棋盘内、与当前格上下左右相邻、两格之间没有挡板、目标格为空。合法落点在回合开始时即常驻高亮。
结果
棋子移动到目标格，回合交给机器人；若棋子进入第 1 行，立即结算为胜利。
边界
被挡板封住的方向不出现落点；点击非高亮格提示具体原因，且不消耗回合。
FR-04跳跃

跳过对手

保证两枚棋子相邻时仍存在可执行的动作，同时避免棋子互相堵死。

触发
你尝试移动的方向上，相邻格被机器人占据，且你与该格之间没有挡板。
处理
按 R-03 依次尝试：正后方可达时执行直线跳跃；正后方越界或被挡板隔开时，在对手两侧计算斜跳落点；两种跳跃都不可行时，该方向不可移动。
结果
跳跃与普通移动同属一个动作，不额外消耗回合；跳跃落入第 1 行同样立即获胜。
边界
不能跳过棋盘边界或挡板，不能落在对手所在格；斜跳落点必须为空，且对手与落点之间不能有挡板。无合法落点时该方向不显示任何标记。
FR-05挡板

放置挡板

让玩家通过改变地形争夺路线优势，这是本作区别于普通走格子游戏的核心。

触发
你的回合，切换至“横板”或“竖板”模式，并在两个格子之间的缝隙上确认放置。
处理
按 R-04 与 R-05 校验：库存大于 0、位置在棋盘内部、不与既有挡板重叠、横竖挡板允许 L 形与 T 形相接（仅禁止双方中段相交的十字形）、放置后双方都至少保留一条通路。悬停显示半透明预览；触屏首次点击预览，再次点击同一位置确认。
结果
挡板固定到棋盘，库存减 1，回合交给机器人；操作模式回到“移动”。
边界
非法放置不改变棋盘与库存，也不消耗回合，预览与提示直接说明原因；库存为 0 或不存在任何合法槽位时，横板 / 竖板模式不可用。
FR-06机器人

机器人回合

让单人玩家始终有一个合法、可预期、强度可选的对手。

触发
你的有效行动结束，且无人抵达目标行。
处理
锁定棋盘输入，显示“机器人思考中”；机器人依据所选难度选择一个合法行动并执行。三档难度都会使用挡板，差异体现在使用频率、落点选择与对玩家回应的评估深度。行动规则、挡板库存与可见信息与玩家完全一致。
结果
行动以与玩家一致的动画与标记呈现，回合回到你；若机器人进入第 13 行，立即结算为你失败。
边界
机器人不得跳过回合、连续行动或使用玩家不可见的棋盘信息；若没有合法挡板位置，只能移动。思考期间页面保持可响应，规则入口暂时不可用。

三档难度行为

难度可观察行为适合
简单大多数回合直接朝目标前进；会偶尔放置挡板，但落点选择随机；对玩家的绕行反应迟钝。首次接触规则。
困难会在前进与延缓之间取舍，主动用挡板拉长你的路线；对你的近距离推进有封锁意识。已熟悉规则，希望有来有回。
地狱会评估你对它行动的回应，优先构造长绕行，并在你接近终点时封锁；自身路线效率高。希望被认真对抗。
难度只来自决策质量。三档难度使用相同的规则、挡板数量与信息集；具体公平约束见 R-07。
FR-07回合与拒绝

回合推进与非法操作

保证每一手都只产生一个有效状态变化，并且被拒绝的操作有可理解的原因。

触发
任意棋盘操作提交。
处理
校验操作者、状态与目标位置；合法则执行唯一动作并交换回合；非法则拒绝并显示原因。常见原因包括：尚未轮到你、目标不是合法落点、方向被挡板封住、跳跃落点不可用、挡板重叠、挡板十字交叉、放置后一方无路可走、挡板已用尽。
结果
非法操作不改变棋盘、库存、回合数或上一手标记；对局停留在原状态，玩家可立即重新选择。
边界
机器人回合与结算阶段拒绝所有棋盘操作；同一非法操作重复提交时给出相同原因。重新开始仅在玩家回合可用，并且必须二次确认。
FR-08结算

胜负结算与再来一局

明确结束条件，并让玩家无需返回首页即可继续下一局。

触发
任一方的棋子在完成一次行动后位于对方目标行。
处理
该动作完成时立即冻结对局；展示胜者、难度、结束原因（抵达第 1 行或第 13 行）以及本局总手数；提供“再来一局”与“调整难度”。
结果
再来一局重置棋盘与双方库存，保留当前难度，玩家仍为先手；调整难度回到准备阶段。
边界
通过跳跃进入目标行同样获胜（见 R-03）；对局结束后不再接受棋盘操作。对局终止规则见 R-06，刷新页面会丢失对局与结算结果。
FR-09规则查阅

游戏内规则

让玩家在准备阶段和思考途中都能确认规则，而不必离开棋盘。

触发
准备阶段、玩家回合或结算阶段点击“规则”。
处理
打开只读规则面板，内容与第 06 章 R-01 至 R-08 一致；机器人回合时入口不可用，避免玩家在对手行动期间改变上下文。
结果
关闭面板后回到打开前的状态；查阅行为不消耗回合、不改变棋盘。
边界
规则文案只保留一份权威定义；界面内的简述不得与第 06 章产生冲突。
06

共享规则

Canonical Rules

本章是规则的唯一权威定义。界面提示、机器人决策与验收讨论都以本章为准；其他章节只引用规则编号。

R-01

坐标、出生与先手

棋盘为 13 列 × 13 行，列自左向右为 1–13，行自上而下为 1–13，坐标统一写作 (列, 行)。你的出生点为 (7, 13)，目标行为第 1 行；机器人的出生点为 (7, 1)，目标行为第 13 行。你固定先手。

R-02

移动

每回合必须执行且只能执行一个动作。普通移动为：从当前格走到上下左右相邻的一格，并同时满足以下条件：

  • 目标格在棋盘内；
  • 目标格为空；
  • 两格之间没有挡板。

除 R-03 规定的跳跃外，不允许斜走、停留或一次移动多格。

R-03

跳跃

当你要移动的方向上，相邻格被对手占据，且你与对手之间没有挡板时，可以跳跃。跳跃优先级固定如下：

  1. 直线跳跃：若对手正后方的格子仍在棋盘内、为空，且对手与该格之间没有挡板，则只能跳到该格。
  2. 斜向跳跃：若正后方越界，或对手与正后方之间存在挡板，则可以跳到对手左右两侧（垂直于原移动方向）的相邻空格。落点必须仍在棋盘内，且对手与落点之间没有挡板。
  3. 不可跳跃：若直线与斜向都没有合法落点，则该方向不可移动。
相邻情况可用动作
对手不在相邻格，且该格为空、无挡板正常移动到该格。
对手在相邻格，正后方在棋盘内、为空、无挡板只能直线跳到正后方，不提供斜跳选项。
对手在相邻格，正后方越界或被挡板隔开斜跳到对手两侧的合法空格；两侧都不可用时，该方向不可移动。
你与对手所在的相邻格之间存在挡板不能进入该格，也不能跳跃。

跳跃消耗本回合唯一的动作，不额外获得第二次行动；跳跃落在目标行时立即获胜。棋子始终不能停留在对手所在格。

R-04

挡板的形状与放置

每方开局拥有 10 块挡板，双方剩余数量始终公开。放置挡板替代本回合的移动动作，消耗一块库存，并且永久留在棋盘上，直到本局结束。

  • 横向挡板：放在第 r 行与第 r+1 行之间，横跨第 c 列与第 c+1 列，阻止这两列上的上下移动。
  • 竖向挡板：放在第 c 列与第 c+1 列之间，纵跨第 r 行与第 r+1 行，阻止这两行上的左右移动。
  • 可放位置：只存在于棋盘内部的格子缝隙。横向与竖向各 12×12 个锚点，不能放在棋盘外沿。
  • 重叠：两个挡板不得覆盖同一条格子缝隙。同一方向上，两个锚点相距小于 2 格（包括完全相同的位置）即共享边缝，视为重叠。
  • 端头与中段相接：同一方向的挡板可以在端点相接；横向与竖向挡板允许端头对端头，形成 L 形，也允许一块挡板的端头落在另一块挡板的中段，形成 T 形。
  • 中间交叉：仅当交点同时位于两块挡板的中段时，形成十字形，禁止放置。
  • 棋子附近：挡板不占据格子，可以贴着棋子放置，只要不构成重叠或十字交叉，并满足 R-05 的通路约束。
R-05

通路保护

任何挡板在确认放置前，都必须检查放置后的棋盘：从双方棋子各自当前格出发，仍能通过未被挡板隔断的上下左右移动到达各自目标行的至少一个格子。两条通路都必须存在，否则该挡板不允许放置。

通路判定不考虑棋子占位。只依据棋盘边界与挡板判断连通性。原因是棋子可以跳跃，且规则不允许任何一方被完全封死；若把对手棋子当作障碍，会产生与跳跃规则冲突的误判。

该约束与挡板离棋子的远近无关：即使挡板放在棋盘另一侧，只要它使某一方失去全部通路，仍然禁止。

绕远路是允许的。通路只判断“能否走到”，不限制绕行步数：把对手逼得多走十几步属于合法战术，只有让某一方彻底无路可走时才禁止放置。
R-06

回合与胜负

  • 你先手；双方交替行动，每回合只执行一个动作。
  • 不允许跳过回合、连续行动或撤回已完成的动作。
  • 任一方棋子进入对方目标行（你到第 1 行，机器人到第 13 行）时，该次行动完成即获胜。
  • 跳跃进入目标行同样获胜；胜负在动作完成时立即判定，不再进入对方回合。
  • 本期不设平局、计时与回合上限；玩家可以随时重新开始一局。
R-07

机器人公平性

机器人必须使用与玩家完全相同的规则、挡板库存、棋盘信息与胜负条件。三档难度之间的差异只能来自决策质量，不允许通过以下方式制造难度：

  • 给机器人额外挡板或放宽移动、跳跃、放置限制；
  • 读取玩家的未提交意图、鼠标轨迹或未来操作；
  • 在简单档故意执行非法动作，或在地狱档隐藏其行动依据；
  • 通过牺牲规则一致性制造“让子”或“补偿”。

机器人完成行动后，其移动、跳跃或挡板必须与玩家操作具有相同的视觉标记与状态提示。

R-08

非法操作

任何违反 R-01 至 R-06 的操作均被拒绝。拒绝时：

  • 棋盘、挡板库存、回合数与上一手标记都不发生变化；
  • 界面立即显示具体原因，而不是只给出“操作无效”；
  • 操作权仍属于原行动方，玩家可以立即重新选择；
  • 机器人回合与结算阶段提交的任何棋盘操作一律拒绝。

07

界面与交互

Interface & Interaction

界面只承担三件事：让棋盘成为唯一焦点、让当前可做的动作一目了然、让每一个被拒绝的操作都有原因。

7.1 布局区域

对局状态区

当前回合、难度、双方挡板余量、重新开始与规则入口。桌面宽屏放在棋盘侧边，窄屏移到棋盘上方或下方，不遮挡棋盘。

棋盘区

13×13 棋盘位于视觉中心，90° 正俯视，无透视与倾斜。目标行以低饱和色带与文字标注。

操作区

三种模式：移动、横向挡板、竖向挡板。模式切换不消耗回合；放置挡板后回到移动模式。

结算层与规则层

结算覆盖棋盘但保留最终局面可见；规则面板在对局中打开时只读，不执行任何动作。

7.2 视觉方向

  • 视角：正交俯视，棋盘平面与屏幕平行；阴影仅用于区分层级，不制造 3D 透视。
  • 棋盘：暖木色底、深褐格线；目标行分别使用朱砂与深青的低饱和色带，避免与棋子混淆。
  • 棋子：你为琥珀色圆形，机器人为深青色方形，并分别标注“你”与“AI”，不以颜色作为唯一区分手段。
  • 挡板：深色实体条，横竖方向清晰；可放置槽位在预览时以高亮显示，非法槽位以朱砂色提示。

7.3 交互状态

状态棋盘表现可操作提示
准备显示初始棋子位置，棋盘被开始面板覆盖。选难度、开始、查看规则。“你执下方棋子，先行。”
你的回合 · 移动所有合法落点以圆点标出；跳跃落点使用环形标记。点击高亮格；切换到挡板模式。“点击高亮格移动。”
你的回合 · 挡板悬停位置显示半透明挡板预览，合法为金色，非法为朱砂色。点击合法槽位；Esc 或“移动”返回。非法预览直接显示拒绝原因。
机器人回合棋盘只读，棋子行动以与玩家一致的动画呈现。无；规则入口暂时不可用。“机器人思考中。”
结算最终局面保留可辨。再来一局、调整难度。显示胜者、抵达行与总手数。

7.4 反馈与可访问性

  • 即时反馈：合法目标常驻高亮；非法点击立即给出原因并轻晃棋盘，但不改变任何状态。
  • 触屏：挡板采用“首次点击预览、再次点击确认”，避免误放；棋盘交互区域随棋盘等比缩放，不裁切。
  • 响应式：桌面端棋盘在游戏区域内完整显示；窄屏时状态区移动到棋盘下方，棋盘保持正方形且不产生横向滚动。
  • 非颜色依赖：双方棋子同时以形状与文字区分；挡板合法与非法预览同时使用颜色与提示文案。
  • 免打断：对局中不使用阻塞式弹窗；除“重新开始”需要二次确认外，所有操作在棋盘内直接完成。
